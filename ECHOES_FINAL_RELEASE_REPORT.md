## 1. Project status

ECHOES is a real-time planetary exploration system: a navigable solar system,
ten real spacecraft on their real destinations, and a documentary layer with
source-linked mission records for every device. The production build ships
clean, the public repository is live, the deployment is verified in a fresh
browser session, and 160 automated tests pass.
