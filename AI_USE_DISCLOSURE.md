# AI Use Disclosure

ECHOES was developed with help from AI coding assistants. We are disclosing that use because it affected substantial parts of the work.

## Where AI tools were used

AI coding assistants helped with:
- drafting and refactoring application code and 3D scene logic;
- creating and revising tests, scripts, and development documentation;
- organizing mission research and preparing first drafts of explanatory text.

The team remains responsible for the project, its decisions, and the accuracy of the material it submits. AI-generated drafts are not treated as scientific evidence. Mission facts should be checked against the sources linked in the application and in the [mission source register](MISSION_SOURCE_REGISTER.md).

## Images, models, textures, and sound

The project does not present AI-generated images or video as NASA archival material. The creators, source pages, licence notes, and reconstruction status for visual assets are recorded in [ASSET_LICENSE_AND_ATTRIBUTION.md](ASSET_LICENSE_AND_ATTRIBUTION.md).

Some interface sounds and ambience are generated in the browser using Web Audio code. They are original interface effects, not recordings from a NASA mission and not AI-generated audio. Any archival audio used in a documentary is identified separately in the asset register.

## What this disclosure does not mean

- NASA did not build, review, approve, or endorse ECHOES.
- An AI-assisted explanation is not a primary source.
- A reconstructed spacecraft model is not an official NASA model unless the asset record identifies it as one.
- A citation does not prove that a dataset meets the selected challenge's Global Awards eligibility requirement. The team must match an actually used dataset to the official challenge Resources list.
